# Customer & Sales Analysis Using SQL

## Overview
This project analyzes customer purchasing behavior, product performance, and sales trends using SQL.

## Tools Used
- MySQL
- Joins, Aggregations, Subqueries, Window Functions

## Key Analysis
- Monthly sales trend
- Top customers by revenue
- Category-wise performance
- Repeat vs new customers
- Customer revenue ranking

## Business Insights
- A small group of customers contributes most revenue.
- Repeat customers generate higher lifetime value.
- Seasonal patterns influence monthly sales.
- Certain product categories dominate performance.

## Outcome
This analysis supports data-driven marketing, customer retention, and revenue optimization.
